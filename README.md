# 🗒️ ElNotes (v2)  
**Aplikasi Pencatatan dengan Integrasi RESTful API**  
[Submission: *Belajar Fundamental Front-End Web Development - Dicoding*](https://www.dicoding.com/academies/163-belajar-fundamental-front-end-web-development)

## 📖 Deskripsi  
**ElNotes v2** merupakan versi pengembangan lanjutan dari aplikasi pencatatan catatan pribadi yang sebelumnya telah dibangun pada versi pertama. Di versi ini, aplikasi telah ditingkatkan dengan **integrasi RESTful API**, pengelolaan dependensi modern menggunakan **package manager**, dan proses **bundling** dengan **module bundler (Webpack)**.

Fitur dasar dari ElNotes v1 tetap dipertahankan, namun kini seluruh data tidak lagi disimpan di localStorage, melainkan terhubung ke **layanan back-end** secara online menggunakan teknik **Asynchronous JavaScript Request** (AJAX/fetch).

## 🎯 Tujuan Pembelajaran  
Versi ini dikembangkan untuk mengasah keterampilan dalam hal:

- Pengelolaan **JavaScript packages** menggunakan **NPM**
- Penggunaan **Webpack** sebagai **module bundler**
- Teknik **asynchronous** (async/await, fetch API) untuk mengambil dan mengirim data ke server
- Struktur proyek yang lebih modern dan scalable
- Pemisahan kode menjadi modul-modul JavaScript

## 🚀 Teknologi yang Digunakan
- HTML5  
- CSS3 (Grid Layout)  
- JavaScript (ES6 Modules)  
- Web Components (Custom Elements & Shadow DOM)  
- **RESTful API**  
- **NPM** untuk package management  
- **Webpack** untuk module bundling
