# 🗒️ ElNotes (v1)  
**Aplikasi Pencatatan Sederhana (Notes App)**  
[Submission: *Belajar Fundamental Front-End Web Development - Dicoding*](https://www.dicoding.com/academies/163-belajar-fundamental-front-end-web-development)

## 📖 Deskripsi  
**ElNotes** adalah aplikasi pencatatan berbasis web yang memungkinkan pengguna untuk menulis, menyimpan, dan mengelola catatan secara sederhana dan efisien. Proyek ini merupakan bagian dari submission kelas **Belajar Fundamental Front-End Web Development** di Dicoding.

Pada versi pertama (**v1**) ini, pengguna dapat:
- Menambahkan catatan baru melalui formulir
- Melihat daftar catatan aktif dan yang diarsipkan
- Mengarsipkan dan menghapus catatan
- Menyimpan data catatan secara permanen di browser menggunakan **localStorage**

## 🎯 Tujuan Pembelajaran  
Aplikasi ini dibangun untuk mengaplikasikan materi-materi penting yang telah dipelajari selama kelas, seperti:

- Pembuatan **formulir HTML** secara semantik dan valid
- Penyusunan layout menggunakan **CSS Grid Layout**
- Penggunaan **Web Component** untuk membangun UI yang modular dan reusable
- Pengelolaan data menggunakan **JavaScript** dan penyimpanan dengan **localStorage**

## 🚀 Teknologi yang Digunakan
- HTML5  
- CSS3 (Grid Layout)  
- JavaScript (ES6)  
- Web Components (Custom Elements & Shadow DOM)  
- localStorage API
